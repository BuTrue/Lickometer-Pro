# Lickometer Pro v1.7.0

## 更新内容

首个公开发行版。
- PySide6 界面，中文安装向导，支持覆盖升级
- 支持 TXT / CSV / XLSX / LabChart .adicht
- 双瓶（正/负极性）与单瓶分析；爆发、餐次、爆发内频率等 30+ 指标
- Lick AI 模型训练与 ONNX 推理
- 14 类图表、Excel 多工作表导出、文件夹批量分析
- 启动自动检查更新，下载后自动覆盖安装

## What's new

First public release.
- PySide6 interface with a Chinese setup wizard and in-place upgrades
- Reads TXT / CSV / XLSX / LabChart .adicht
- Dual-bottle (positive/negative polarity) and single-bottle analysis; 30+ burst, meal and intraburst metrics
- Lick AI model training with ONNX inference
- 14 plot types, multi-sheet Excel export, folder batch analysis
- Automatic update check on startup with in-place install
